# Solo-Assignment-1_Stufe_A
## Setup
### Voraussetzungen
- Node.js installiert
### Schritte zum Ausführen
- Ordner erstellen:
```
mkdir Ordername
```
```
cd Ordername
``` 
- Repository klonen:
```
git clone https://github.com/Mardalon/Solo-Assignment-1_Stufe_A.git
```
```
cd Solo-Assignment-1_Stufe_A
```
- Abhängigkeiten installieren:
```
npm install
```
- Development-Server starten:
```
npm run dev
```
Browser unter der im Terminal angezeigten Adresse (standardmäßig http://localhost:5173) öffnen.
